A step-by-step guide covering the entire corporate loan lifecycle, from application creation through legal review, security perfection, and final disbursement. Every role, button, and status transition is documented with exact values.

⚠
Approval Gate (CreditAnalysis): The gate for this stage checks that every bank statement has a completed cashflow analysis. If any statement shows "Pending" analysis, the gate will block or warn. Run analysis on all statements before proceeding.

Set Collateral Valuations

The Credit Officer (or HO Reviewer) is the only role that can set collateral valuations. Valuations must be entered here — the CreditAnalysis approval gate will block if any collateral item is still in "Proposed" status.

  1. Click the Collateral tab.
  2. Click the valuation icon (☑ fact_check) on the Real Estate item.
    Market Value (₦)220000000
    Forced Sale Value (₦)165000000
    Haircut (%)25
  3. Click Save Valuation. Status changes to Valued.
  4. Repeat for the Fixed Deposit item: Market Value 50000000, FSV 50000000, Haircut 10.
⚠
Collateral approval is deferred. You cannot approve collateral yet — the approve button is greyed out because legal clearance has not been recorded. The Legal Officer will record legal clearance in Step 11. After that, you will approve the collateral in Step 13.

Approve Guarantor

  1. Click the Guarantors tab.
  2. The guarantor's status should now be CreditCheckCompleted (auto-triggered after branch approval).
  3. Click Approve on the guarantor and confirm.

Generate AI Advisory

  1. Click the Advisory tab.
  2. Click Generate Advisory.
  3. The system aggregates bureau reports, financials, cashflow, collateral, and guarantors to produce:
    • Score matrix across 5 risk categories (Credit History, Financial Health, Cashflow, DSCR, Collateral)
    • Overall recommendation (Approve / Decline / Refer)
    • Red flags, mitigating factors, and recommended terms
  4. Review the advisory report displayed in the tab.

  6. Click Save.
✔
Both collateral items are now legally cleared. The LegalReview approval gate is satisfied. The Approve button in the action bar is now enabled.

TroubleshootingCommon issues and solutions

Login fails with "invalid credentials"

  • The login field uses the user's email address (e.g., adewale.johnson@crms.ng), not a short username. The password for all @crms.ng accounts is Password1$$$ (three dollar signs).
  • Ensure the database was seeded by ComprehensiveDataSeeder. Verify by checking that adaeze.nwosu@crms.ng and chidi.okafor@crms.ng appear in the admin users list.

Cannot see "Submit for Review" button

  • Only visible when status is Draft and you are logged in as a Loan Officer.

Cannot see Approve / Return / Reject buttons

  • These buttons are role-and-status specific:
    StatusWho Sees Approve
    BranchReviewBranchApprover
    CreditAnalysisCreditOfficer
    HOReviewHOReviewer
    LegalReviewLegalOfficer
    LegalApprovalHeadOfLegal
    FinalApprovalFinalApprover
    OfferAcceptedOperations
    SecurityPerfectionLegalOfficer
    SecurityApprovalHeadOfLegal
    DisbursementPendingOperations
  • Log in with the correct role for the application's current status.

Collateral "Approve" button is greyed out

  • The approve button is disabled until the collateral item has both: status = Valued AND legal clearance recorded.
  • Ensure the Credit Officer set the valuation (Step 8) and the Legal Officer recorded legal clearance (Step 11).
  • After both are done, log in as Credit Officer (or HOReviewer) to approve the collateral (Step 13).

LegalReview Approve button is blocked (gate)

  • The LegalReview gate checks that all collateral items have legal clearance recorded.
  • The Legal Officer must click the ⚖ gavel icon on each collateral item and save clearance notes before the Approve button becomes active.

CreditAnalysis gate blocks approval

  • The CreditAnalysis gate checks: (1) all bank statements have completed cashflow analysis, (2) all collateral items have valuations entered (not "Proposed"), (3) all guarantors are approved.
  • Run cashflow analysis on the Statements tab for every statement.
  • Set valuations on the Collateral tab for every item.
  • Approve all guarantors on the Guarantors tab.

FinalApproval gate blocks the Final Approver

  • The FinalApproval gate requires: documents verified, bank statements analysed, collateral fully Approved (not just Valued), guarantors Approved.
  • The most common cause is collateral stuck at "Valued" — the Credit Officer must approve it (Step 13) before the Final Approver acts.

Application invisible to Operations or GM Finance after approval

  • Both roles have global visibility. If the application does not appear in their list, check the application's status in the admin or Credit Officer view (uche.eze@crms.ng).
  • A desync between LoanApplications.Status and WorkflowInstances.CurrentStatus can make an application invisible to all queues. This is repaired automatically by the ComprehensiveDataSeeder repair blocks on the next application restart.

"Disburse" button not visible to GM Finance

  • The Disburse button is only visible to GM Finance (and System Admin) when status is DisbursementHQApproval.
  • If the status is still DisbursementPending, Operations must complete Step 22 (Approve) first.
  • If the status is OfferAccepted, the security perfection stages (Steps 19–22) have not been completed yet.

"Record Acceptance" button not visible or confirm button disabled

  • The button is only available to Operations when status is OfferGenerated.
  • The Confirm button inside the modal stays disabled until: Acceptance Date is set, Acceptance Method is selected, KFS Acknowledged is ticked, and all Conditions Precedent are satisfied.

"Setup Committee" button not showing

  • Visible only when: status is CommitteeCirculation, no committee exists yet for this application, and you are logged in as Credit Officer.

Status stuck at CommitteeApproved (application invisible)

  • CommitteeApproved is a transient state — the system auto-advances to FinalApproval in the same request as the committee chairperson's Record Decision action.
  • If an application is somehow stuck at CommitteeApproved, restart the application — the seeder repair blocks will advance it to FinalApproval.

Committee voting: "Cast Vote" not available

  • Committee members can only vote on applications where they are assigned to the committee for that application.
  • Ensure Step 13 (Setup Committee) was completed first — the committee must be set up by the Credit Officer before members can vote.
  • Each member can only vote once per committee review.

Balance sheet validation fails

  • Total Assets MUST exactly equal Total Liabilities + Total Equity. Example: 2,500,000,000 = 1,200,000,000 + 1,300,000,000.
  • No rounding differences are allowed. Double-check every figure.

Account number "1234567890" returns error

  • Ensure CoreBanking:UseMock is set to true in appsettings.json.

Credit checks not appearing after branch approval

  • Ensure SmartComply:UseMock is true in appsettings.json.
  • BVNs entered for directors/signatories/guarantors must match the mock BVNs in the Mock Data Reference section.
  • Wait a few seconds after branch approval, then refresh and check the Bureau tab.
