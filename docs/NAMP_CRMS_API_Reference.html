CRMS Portal Status API National Agricultural Mechanization Program · Bank of Agriculture · Heifer Nigeria

1. Introduction

This document describes the Portal Status API — a single read-only endpoint that the NAMP applicant portal calls to display the current state of a submitted loan application. It is intended for use on the applicant's status dashboard so that applicants can track their application from submission through to loan activation.

The endpoint is designed to be safe to poll: it never mutates state, it always returns 200 (even when an application is not found), and it surfaces live repayment data from the core banking system for active loans.

What the portal needs to do After a successful application submission, the CRMS API returns an applicationNumber (e.g. NAMP-2026-A1B2C3D4). Store this CRMS application number against the applicant record and use it to call this endpoint whenever the applicant visits their status page. Render the response using the 7 portal statuses and the structured objects described below.

2. Authentication

The same API key used for the submission webhook is used here. Send it in the X-Api-Key header on every request.

HeaderValue
X-Api-KeyThe shared secret key provided by the BOA CRMS team.
Missing or incorrect API key → 401 Unauthorized A plain-text "Invalid or missing API key." body is returned. This is a configuration issue — alert the NAMP technical team.

3. Endpoint

PropertyValue
MethodGET
Path/api/v1/namp/webhook/application/{crmsApplicationNumber}
Path parametercrmsApplicationNumber — the CRMS-assigned application number (e.g. NAMP-2026-A1B2C3D4) returned as applicationNumber in the webhook submission response.
AuthX-Api-Key header required.
ResponseAlways 200 OK with a JSON body. Never returns 404.

4. Integration Flow

NAMP Portal CRMS API │ │ │ Applicant visits status page │ │ NAMP loads stored crmsApplicationNumber │ │ │ │──── GET /api/v1/namp/webhook/application ─────▶│ │ /{crmsApplicationNumber} │ │ Header: X-Api-Key: {key} │ │ │ │ ① Validate API key │ │ ② Lookup recalled app │ │ by ApplicationNumber │ │ ② If not recalled yet: │ │ lookup staging record │ │ → return Received │ │ ③ Map internal status │ │ → portal status │ │ ④ If OfferMade / │ │ Processing: │ │ fetch repayment │ │ schedule from CBS │ │ ⑤ If Active / Closed: │ │ fetch live loan │ │ account data from CBS │ │ │ │◀─── 200 OK ──────────────────────────────────│ │ NampPortalStatusResponse (JSON) │ │ │ │ Render status page using: │ │ • status + statusMessage │ │ • offer (if OfferMade / Processing) │ │ • loanAccount (if Active / Closed) │ │ • timeline[] │
Fineract data enrichment is best-effort When CRMS fetches live data from the core banking system (repayment schedule or loan account details), it wraps the call in a try/catch. If the CBS is temporarily unavailable, CRMS still returns 200 with fineractDataAvailable: false on the offer or loanAccount object. Display the static fields (amount, rate, account number) and show schedule/balance fields as "Calculating…" or "Temporarily unavailable" respectively.

5. Response Schema — Root Object

Field Type Description
applicationReferencestringEchoes back the CRMS application number that was queried (e.g. NAMP-2026-A1B2C3D4). Always present.
foundbool true if the application exists in CRMS (either recalled or awaiting assignment).
false only if the CRMS application number is completely unknown — in this case only statusMessage is populated; all other fields are null or empty.

statusMessagestring?Human-readable sentence suitable for display directly to the applicant. Always present — even when found = false.

lastUpdatedstring? (ISO 8601)UTC timestamp of the most recent status change. null when found = false.

applicationDetailsobject?Core loan request details. null when found = false. See Section 6.2.
offerobject? Loan offer details. Populated only when status = "OfferMade" or "Processing". null for all other statuses. See Section 6.3.
loanAccountobject? Live loan account data. Populated only when status = "Active" or "Closed". null for all other statuses. See Section 6.4.

FieldTypeDescription

6.2 applicationDetails Object

FieldTypeDescription
requestedAmountdecimal?Original loan amount requested, in NGN.

6.3 offer Object

Present only when status is OfferMade or Processing. null otherwise.

When fineractDataAvailable = true, the repayment schedule fields (monthlyInstallment, totalInterest, totalRepayable) are populated with live figures computed from the core banking system. When false, display these as "Calculating…" — the interest rate and approved amounts are always present.

FieldTypeDescription
approvedAmountdecimal?Approved loan principal in NGN.
approvedTenorMonthsint?Approved repayment tenor in months.
interestRatePerAnnumdecimalAnnual interest rate as a percentage, e.g. 9.0 = 9% p.a. Always present.
monthlyInstallmentdecimal?Computed monthly EMI in NGN. null if fineractDataAvailable = false.
totalInterestdecimal?Total interest payable over the full tenor in NGN. null if fineractDataAvailable = false.
totalRepayabledecimal?Total amount to be repaid (principal + all interest) in NGN. null if fineractDataAvailable = false.
fineractDataAvailablebooltrue if a live repayment schedule was successfully fetched from the core banking system.

6.4 loanAccount Object

Present only when status is Active or Closed. null otherwise.

When fineractDataAvailable = true, all balance and repayment fields reflect the current live state of the loan account. When false, only fineractLoanId and loanAccountNumber may be present — show balance fields as "Temporarily unavailable".

FieldTypeDescription
fineractLoanIdlong?Internal CBS loan ID (for reference only — not displayed to applicants).
loanAccountNumberstring?Loan account number as assigned by the core banking system. Display this to the applicant.
disbursedAmountdecimal?Amount actually disbursed in NGN.
disbursedAtstring? (ISO 8601)Date and time of disbursement.
outstandingBalancedecimal?Current total outstanding balance in NGN.
nextInstallmentDueDatestring? (ISO 8601)Due date of the next repayment installment. null for fully repaid / closed loans.
nextInstallmentAmountdecimal?Amount due on the next installment date in NGN.
arrearsAmountdecimal?Amount currently overdue in NGN. null when not in arrears.
isInArrearsbool?true if the account has any overdue charges. null if fineractDataAvailable = false.
fineractDataAvailablebooltrue if live loan account data was successfully fetched from the core banking system.

6.5 timeline[] Entries

An ordered array of status change events from oldest to newest. Each entry represents a moment when the application moved from one internal stage to another. This can be used to build a visual progress timeline for the applicant. Empty array when found = false.

FieldTypeDescription
stagestringHuman-readable stage label. See Section 10 for all possible values.
occurredAtstring (ISO 8601)UTC timestamp when this stage was entered.
notestring?Optional note recorded by the loan officer at this stage. null if no note was added.

7. Portal Status Values

The status field will be one of the following 7 string values. Use these to drive your UI logic.

ValueDisplay (suggested)statusMessage (from CRMS)Action for applicant
UnderReview Under Review "Your application is currently under review. Our team will assess all information provided before making a decision." No action required. Check back later.
NotApproved Not Approved "We regret to inform you that your application was not successful at this time. Please see the reason below or contact your nearest BOA branch for more information." Display declineReason if present. Direct applicant to nearest BOA branch.
OfferMade Offer Made "Congratulations! Your loan application has been approved. Please review the offer details below and countersign your offer letter to proceed." Show offer object. Prompt applicant to countersign their offer letter. Note: offer has a limited validity window.
Processing Processing "Your offer has been accepted and your loan is being processed. You will be contacted once the equipment is ready for deployment." No action required. Show offer object for reference.
Active Active "Your loan is active. Please see the account details below for your repayment schedule information." Show loanAccount object with outstanding balance and next installment date.
Closed Closed "Your loan has been fully repaid. Thank you for your participation in the NAMP programme." Show loanAccount for historical reference. No outstanding balance.
OfferLapsed Offer Lapsed "Your loan offer has lapsed as it was not accepted within the required timeframe. Please contact your nearest BOA branch if you wish to re-apply." Direct applicant to nearest BOA branch.

8. Internal → Portal Status Mapping

CRMS has a detailed internal workflow. This table shows how every internal stage maps to the 7 portal statuses, so you know exactly what status value to expect at each point in the process.

Portal StatusInternal CRMS Stages included
UnderReview Staging (not yet recalled): Application Received — minimal response, bvn and requestedTenorMonths are null.
Recalled: Pending Assignment, Application in Progress, Application Submitted, Technical Appraisal, Financial Appraisal, Branch Credit Committee Review, Zonal Credit Committee Review, Regional Credit Committee Review, Head Office Credit Committee Review, Ratification
NotApproved Technical Appraisal — Declined, Financial Appraisal — Declined, Branch Credit Committee — Declined, Zonal Credit Committee — Declined, Regional Credit Committee — Declined, Head Office Credit Committee — Declined, Ratification — Declined, Declined
OfferMade Offer Letter Generated
Processing Offer Accepted, Pre-Deployment Verification, Training, Equipment Deployment
Active Loan Activated
Closed Loan Closed
OfferLapsed Offer Lapsed
